
# React Portfolio Starter

A clean, fully responsive portfolio built with React + Vite and a near black/white aesthetic.
Includes animated hero, projects grid, experience, and a contact form (mailto).

## Quick start
```bash
npm install
npm run dev
```

## Customize
- Edit placeholder content in `src/data/site.js` (name, role, tech, projects, socials).
- Replace avatar (Hero) by swapping the text initials with an `<img src="/your-photo.jpg" />`.
- Drop your `resume.pdf` into the project root (optional).
- Update colors in `src/styles/app.css` by tweaking CSS variables.

## Deploy
- Build: `npm run build`
- Deploy the `dist` folder to Netlify, Vercel (static), or any static host.
